Панель управления: **https://kvartal.example/panel.html** (пароль — в `.pass-note`, рядом с этим файлом)

Хостинг reg.ru, аккаунт `u3630287`, папка сайта `/www/kvartal.example`.
Доступы для заливки лежат в `~/.kvartal-ftp` (chmod 600).

## Что это

Светлая витрина в бело-зелёной гамме (`#85bb65`) по референсу клиента
(Fintech Landing Page с Behance): тёмно-зелёный экран приветствия, лента
логотипов партнёров, каталог из трёх вкладок и блок «как это работает».

Каталог — 29 офферов клиента:

| Раздел | Карточек |
|---|---|
| Дебетовые карты | 9 |
| Кредитные карты | 6 |
| МФО | 14 |

Все партнёрские ссылки перенесены из ТЗ побайтно, вместе с `erid` и
`platform_id`. Сверка: `grep -o '"url": "[^"]*"' data.js`.

## Заливка

```bash
bash deploy.sh              # сайт без каталога: data.js на сервере правит клиент
bash deploy.sh --with-data  # вместе с каталогом (затрёт правки клиента!)
```

Скрипт сам выставляет права 664 на `data.js` и html (панель их переписывает)
и в конце проверяет живой сайт: главную, панель, `api.php`, `data.php`,
логотипы.

## Про зелёный — важно для правок

`#85bb65` на белом даёт контраст **2,26:1**. Это ниже минимума даже для
крупного текста, поэтому в CSS он живёт только как заливка:

* `--green` `#85bb65` — фон кнопок, плашек, тёмных блоков;
* `--green-ink` `#3f7020` — «зелёный текст», 5,9:1 на белом;
* `--green-line` `#5e9b3c` — значки и заметные рамки, 3,4:1.

Не переносите `--green` в `color`, `border-color` или `outline`.
Проверка: `grep -n "#85bb65" css/style.css` — каждое попадание должно быть
фоном.

## Цифры в карточках

В карточках намеренно **нет выдуманных ставок, лимитов и процентов**:
крупная строка говорит о сути («Кэшбэк за покупки», «Льготный период»,
«Деньги на карту»), а условия описывают процесс (заявка онлайн, документы,
доставка). Как только клиент возьмёт точные цифры из своей партнёрки, он
вписывает их в панели в поле «Крупная строка выгоды» — это одна минута на
карточку. Цифра «на глаз» в рекламе финансовых продуктов — прямой путь к
блокировке оффера партнёркой и к вопросам ФАС.

## Что проверено

* 29 карточек, 29 ссылок, все совпадают с ТЗ;
* вкладки: стрелки, Home/End, roving tabindex, панели скрыты `hidden`;
* доступные имена всех 29 кнопок уникальны («Оформить — Карта Ozon, Ozon Банк…»);
* нет дублей `id`, иерархия заголовков H1 → H2 → H3 без пропусков;
* нет горизонтального скролла на 320 px;
* панель: вход, правка, «Сохранить на сайт», «Вернуть предыдущую версию» —
  проверено и локально, и на боевом сервере;
* логотипы у всех 29 карточек, плашек с инициалами не осталось.

## Логотипы Фора-Банка и «Умных наличных» (10.09.2026)

Взяты с официальных сайтов и приведены к общему виду:

* `forabank.svg` — с forabank.ru (сайт под сертификатом Минцифры, curl его не
  берёт: качается из браузерной сессии). Из логотипа оставлен только знак,
  надпись «ФОРАБАНК» удалена — в квадратной плашке 52 px она нечитаема.
  Убран `overflow="visible"`, иначе обрезка viewBox не работает.
* `smartcash.svg` — знак «Умных наличных» с smartcash.ru (бренд ООО МКК
  «Умный заём»). Из исходника выброшены 13 путей с надписью: они были белыми
  под тёмную шапку и на белой карточке исчезали. viewBox обрезан по знаку.
